MODEL CONNECTION

配置 DeepSeek API

快速导入与原文检索完全离线；深度解读默认覆盖全文分块，支持 JSON 重试与断点恢复。高质量模式先分析再抽取，调用次数更多。模型问答和跨论文综合需 API Key。

PRIVACY

数据与安全

原始论文和 Wiki 保存于本地。模型调用时，所选论文片段可能发送至 DeepSeek。工作台仅供本机使用，不提供公网鉴权。

删除本地 Key 不等于在 DeepSeek 平台撤销。若系统环境变量仍配置了 Key，模型连接可能继续可用。
